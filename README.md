# Aery

一个需要自己接入api和角色聊天的前端小手机。

它最开始只是一个简单的小手机网页，后来一点点塞进了聊天、桌面组件、音乐、论坛、朋友圈、小游戏和各种奇奇怪怪的功能，于是逐渐变成了现在这个什么都有一点的玩具。

并且后续仍然会随兴趣更新新的功能。

---

## ✦ 使用方式

Aery 目前主要有以下几种使用方式：

### 网页版

通过 GitHub Pages 直接打开即可使用。

由于 GitHub Pages 在部分网络环境下可能访问不稳定，如果网页打不开，可以尝试：

- 使用 APK 版本
- 下载 ZIP 后解压，在本地打开其中的 `index.html`

### APK

APK 支持热更新，但部分与 Android 系统级功能相关的功能，例如后台消息通知等，需要下载对应的新版 APK 才能使用 。

目前最新版 APK **优先在群内发布**。

现在的旧版 12.8 版本 APK 不具备后台消息弹窗功能，但其他大部分功能不受影响

## ✦ 一些功能

Aery 目前包含但不限于：

### 桌面

- 多页桌面
- 自定义图标与排布
- 多种主题
- 日间 / 夜间模式
- 壁纸
- 桌面组件
- 音乐组件
- 灵动岛等交互

### 聊天

- 自定义联系人
- 自定义头像与角色资料
- 玩家面具 / 身份
- 单聊与群聊
- 引用、撤回、修改、删除、转发等消息操作
- 翻译
- 角色心声
- 语音通话界面
- 可连接兼容的聊天 API

### 其他

- 音乐、和角色一起听
- 朋友圈
- 论坛
- 备忘录
- 相册
- 工作台
- NO EXIT（不xx就不能出去的小游戏）
- 一些小游戏与实验功能
- ……

Aery 仍然会偶尔加入一些新功能。

## ✦ 关于数据

Aery 的用户数据保存在设备本地。

更换浏览器、清除浏览器数据、卸载应用或进行其他系统操作时，都有可能导致本地数据丢失。

如果有重要内容，建议提前进行备份或导出。

连接第三方 API 时，相关请求会按照所填写 API 服务商的方式进行处理。

请自行确认所使用服务的隐私政策与使用规则。
